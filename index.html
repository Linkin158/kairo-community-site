安卓安装四步走

1

允许「未知来源」安装

Android 8.0 起按「下载来源」单独授权。点安装弹窗里的「设置 / 去开启」，找到你用来下载的浏览器或文件管理器，打开「允许安装来自此来源的应用」。

各品牌常见路径
  • OPPO / realme（ColorOS 12+）：设置 → 密码与安全 → 系统安全 → 外部来源应用，打开对应应用。
  • 华为：设置 → 系统和更新 → 纯净模式 → 关闭「增强防护」；安装界面再授权对应应用。
  • 小米：纯净模式安装页右上角「设置 → 纯净模式 → 授权单次安装」。
  • vivo / 其他：设置 → 应用与权限 / 安全 → 安装未知应用，给下载来源开权限。
2

找到下载的 APK 并点击

一般在浏览器「下载内容」、通知栏下载完成提示，或文件管理的 Download 目录里。

3

确认继续安装

遇到「风险提示 / 禁止安装 / 纯净模式拦截」时，选择「仍要安装 / 继续安装 / 单次授权」。本应用为内测自签名版本，未上架应用商店，属正常提示。

4

安装完成，打开使用

点「打开」进入 App；首次使用可在「我的 → 我的讨论」进入光影社区发帖交流。

常见问题

提示「解析包错误 / 安装包损坏」？

下载不完整或网络中断，重新下载；确认浏览器未被压缩代理改写文件。

提示「出于安全限制，禁止安装」？

回到第 1 步，给当前下载来源开启安装未知应用权限；华为需先关闭纯净模式增强防护。

提示「与已有应用签名冲突 / 无法覆盖安装」？

旧版本若用不同签名安装，需先卸载旧版再装新版（卸载会清除本机收藏与本地草稿）。后续正式版将统一签名保证覆盖升级。

安装后打不开或闪退？

确认系统为 Android 8.0 及以上；在系统设置里清除该应用缓存后重试，并反馈机型与系统版本。
